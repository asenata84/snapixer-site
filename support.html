Getting started

Start Snapixer once from the Start menu. It keeps running in the notification area (next to the clock) when you close its window; use the tray icon menu → Quit to exit.

Enter / Ctrl+CCopy the selection
Ctrl+SSave as PNG

Frequently asked questions

F1 does nothing, or Snapixer says a shortcut could not be registered

Another app already uses that key. Open Settings → Keyboard shortcuts, click the shortcut and press a new key combination. Shortcuts follow the physical key, so they also work with non-Latin keyboard layouts.

How do I recognize text in another language?

Open Settings → OCR → Add a language. The language is downloaded once and then works offline. You can tick up to three languages at a time; fewer languages are faster and more accurate.

How do I set up the AI assistant?

Open Settings → AI assistant, choose a provider, paste your API key and click Save key, then Test connection. The key comes from your account with that provider, which may charge for its use. For a free, local option, install Ollama and choose the Ollama provider; no key is needed. Then select an area with F1 and click ✨ in the toolbar.

How do I start Snapixer with Windows?

Turn on Settings → General → Launch Snapixer when Windows starts. If you turned Snapixer off in Windows (Task Manager or Windows Settings → Apps → Startup), only Windows can turn it back on: Snapixer then shows a button that opens that page.

Where are my screenshots and settings stored?

Saved screenshots go to Pictures\Snapixer by default (changeable in the settings). The history, settings and downloaded OCR languages are in the app's private folder, which Windows keeps for Store apps; the Open folder buttons in Snapixer open it directly. Uninstalling Snapixer deletes that folder; screenshots saved to Pictures stay.

How do I send the log file?

Open Settings → About → Open the log folder and attach main.log to your email. It contains errors and warnings only, without API keys, and is never sent anywhere unless you send it yourself.

Screenshots look pale on my HDR display

On HDR displays Windows may return the screenshot with paler colors. This is a known limitation of the Windows capture API.

Can I select an area across two monitors?

Not at the moment: a selection covers one monitor. Starting a selection on another monitor clears the previous one.

Is there a free trial?

Yes. The Microsoft Store offers a 15-day free trial with every feature. When it ends, Snapixer asks you to buy it before taking new screenshots; your history and settings stay as they are. Buying is done in the Microsoft Store (Settings > About > Buy in Microsoft Store).

How do I get a refund?

Purchases are handled by the Microsoft Store, so refunds are requested from Microsoft through your Microsoft account order history.
